# 어휘 탐험대 사진 넣는 곳

이 폴더(`word-game/photos/`)에 아래 이름 그대로 사진을 넣으면 게임에 바로 나와요.
사진이 없으면 게임에서 "📷 사진 필요"로 표시되고, 다른 그림으로 대신하지 않아요.

## 필요한 사진 (5장)

| 파일 이름 | 사물 | 사진에 꼭 보여야 하는 부분 | 권장 구도 |
|---|---|---|---|
| `bus.jpg` | 버스 | **바퀴**, **문**, (창문) | 버스 옆모습 전체. 앞바퀴·뒷바퀴와 승차 문이 한 장에 같이 보이게. 문은 열려 있으면 더 좋아요. |
| `helicopter.jpg` | 헬리콥터 | **날개(위쪽 프로펠러)**, **꼬리와 꼬리 날개**, (창문) | 헬리콥터 옆모습 전체. 위쪽 큰 날개가 잘리지 않고, 긴 꼬리 끝의 작은 날개까지 보이게. |
| `elevator.jpg` | 엘리베이터 | **버튼**, **문** | 엘리베이터 밖에서 정면. 닫힌(또는 열린) 문과 옆의 버튼(위·아래 호출 버튼)이 한 장에 같이 보이게. |
| `hairdryer.jpg` | 드라이기 | **손잡이**, **바람 나오는 곳**, (전선) | 흰 바탕이나 단순한 바탕에 드라이기 옆모습 전체. 손잡이와 바람 나오는 입구가 모두 보이게. |

(괄호 안 부분은 틀린 곳을 눌렀을 때 "이건 창문이야"처럼 알려주는 데 쓰여요. 없어도 괜찮아요.)

### 사진 고르는 팁
- **사물 하나만, 전체가 다 보이는 사진**이 좋아요. 사람이나 다른 물건이 크게 같이 찍힌 사진은 피해요.
- 가르칠 부분이 **너무 작지 않게** 보여야 해요. 확대해서 보여주기 때문에 큰 사진(가로 1000칸 이상)이면 더 선명해요.
- 사진 안에 큰 **글자나 로고**가 있으면 아이가 글자에 집중할 수 있어서 피하는 게 좋아요.
- 실제 집에 있는 세탁기·드라이기, 아파트 엘리베이터를 **직접 찍은 사진**이면 출처 걱정이 없고, 아이가 실제 물건과 바로 연결하기도 좋아요.
- 파일 형식은 `.jpg`로 맞춰 주세요. 다른 형식이면 `words.js`의 `photo` 이름도 같이 바꿔야 해요.

## 사진을 넣은 다음 할 일
1. 게임 첫 화면 → **부모님 설정 · 기록** → **📐 터치 영역 만들기**를 눌러요.
2. 사물과 부분(예: 버스 → 부분: 바퀴)을 고르고, 사진 위에 손가락으로 끌어서 네모(또는 동그라미)를 그려요.
   - 그린 영역은 그 기기에 바로 저장돼서 곧바로 게임에서 쓸 수 있어요.
   - 확대 범위도 정하고 싶으면 **확대 범위 그리기**를 눌러 그려요. 안 그리면 부분 주변을 자동으로 크게 보여줘요.
3. 다른 기기에서도 쓰려면 **📋 코드 복사**를 눌러서 나온 내용을 전달해 주세요. `words.js`에 넣어 드릴게요.
4. 사진 출처를 `CREDITS.md`에 적어요.

## 새 사물 추가하기
`word-game/words.js`의 `items`에 같은 모양으로 하나 더 넣고, 사진을 이 폴더에 넣으면 돼요.
