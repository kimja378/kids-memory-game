# 필요한 물건을 찾아요 (상황 → 필요한 물건 연결 게임)

만 4세 아동이 **상황을 보고 그 상황에 필요한 물건을 생각해서 고르도록** 만든 게임입니다.
주소: https://kimja378.github.io/kids-memory-game/situation-game/

## 설계 원칙
- 상황 그림에는 정답 물건을 그리지 않습니다 (양치하기 그림에 칫솔이 없음). 같은 그림 찾기로 맞힐 수 없게 하기 위함입니다.
- 그 상황에서도 쓸 수 있는 물건(예: 생일 파티의 접시·컵)은 `accept` 목록에 넣어 **선택지에 나오지 않게** 해서, 맞는 답을 오답 처리하지 않습니다.
- 오답 선택지는 그 상황과 분명히 관계없는 물건만 씁니다.
- 아이 화면에는 점수·오답 횟수를 보여 주지 않고, 기록은 「부모님 기록」에서만 봅니다.

## 난이도
| 단계 | 선택지 | 정답 |
|---|---|---|
| 쉬움 | 2개 | 1개 |
| 보통 | 4개 | 2개 |
| 어려움 | 6개 | 3개 |

## 기능
- 음성 안내(아이패드 Safari 기본 한국어 음성): 상황 설명, 정답 칭찬, 오답 시 「OO는 ~할 때 써요. 다시 찾아볼까요?」
- 힌트 3단계: ① 질문 다시 듣기 ② 필요한 물건의 기능 설명 ③ 남은 정답 물건 반짝임
- 정답을 고르면 그 물건을 사용하는 장면(움직이는 그림)과 설명을 보여 줍니다.
- 같은 상황도 그림(등장인물·배경)을 번갈아 보여 줍니다.
- 학습 기록(이 기기 localStorage): 상황별 한 번에 맞힌 비율, 힌트 사용, 틀린 선택 수, 자주 어려워하는 상황, 최근 기록

## 파일
```
index.html, style.css, game.js   게임
data.js                          물건·상황 데이터 (새 문제는 여기에 추가)
assets/objects/*.svg             선택지 물건 그림
assets/scenes/<상황>-<번호>.svg   상황 그림 (번호마다 다른 인물·배경)
assets/usage/*.svg               맞혔을 때 보여 주는 사용 장면
../tools/situation_art.py        모든 그림을 만드는 스크립트 (그림 수정·추가는 여기서)
../tests/situation-game.test.js  자동 테스트
```

## 새 상황 추가 방법
1. `tools/situation_art.py` 에 상황 그림 함수(정답 물건은 그리지 않기)와 필요하면 새 물건·사용 장면 함수를 추가하고 `python3 tools/situation_art.py` 실행
2. `data.js` 의 `OBJECTS`, `SITUATIONS` 에 항목 추가 (`correct`, `accept`, `distractors`)
3. `node --test tests/situation-game.test.js` 로 확인

## 그림 출처
모든 그림은 이 저장소를 위해 `tools/situation_art.py` 로 직접 그린 SVG입니다. 외부 이미지·이모지를 쓰지 않습니다.
첨부해 주신 언어센터 활동지는 구성과 분위기만 참고했고, 그림은 복제하지 않았습니다.

## 1차 시제품 상황 (5가지)
양치하기, 밥 먹기, 잠자기, 청소하기, 생일 파티 — 나머지 상황(공부하기, 소풍, 목욕, 비 오는 날, 요리 등)은 같은 방식으로 추가합니다.
